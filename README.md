## 📋 Overview

**Mysuru Hair Fixing** is a simple, clean static website built for a local hair salon or hair care service business in Mysuru, Karnataka. The site serves as the online presence for the business, showcasing services, pricing, and contact details.

---

## ✨ Features

- 📄 Services listing and pricing information
- 📍 Location and contact details
- 📱 Responsive design for mobile and desktop
- 📞 Click-to-call and WhatsApp contact options
- ⭐ Customer testimonials section
